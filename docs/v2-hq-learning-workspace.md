# HQ V2 learning workspace prototype
Modernizes the existing language theme workspace without replacing its revision and media RPCs. Real readiness counts (linked images/audio, classification, draft/pending), stage/status/media search filters, responsive virtualized rows, learner-style preview with optional HTTPS media, unsaved editor preview and contextual difficulty objectives. Existing draft save/import/discard/submit/publish confirmation remain authoritative. Adventure authoring is not enabled by this patch. Link counts do not validate file availability, copyright, audio pronunciation or cultural accuracy. No new dependencies or schema changes. Existing branch stays isolated pending CI and real Test1 device/media tests.
