# Fast Upload rollout

Language vocabulary only. Open the existing Bulk Asset Import Studio and select Fast Upload. Windows drag/drop or browse; narrow screens stack. Local draft, 500ms read-only validation, canonical filenames, preview, explicit publish. Term reuse with another meaning is allowed after review; exact duplicate or slug/file conflict blocks create. Existing bulk imports retain missing-link recovery. Shared concept images are available through both bulk import and Fast Upload. Choose Reuse Existing Image to browse/search the global images directory and preview an existing image from any language. The existing path is linked, never copied or overwritten. Missing selected objects block publication even when missing media is allowed. Clear the initial definition-based filename search to browse all images. Audio remains language-specific. Original filenames are reported when present in the relevant folder; only canonical target collisions block upload. File bytes are retained for the current draft only. A failed database commit may leave uploaded but unlinked assets; retry after revalidation reuses byte-identical assets, never auto-deletes. For an uncertain response check the vocabulary list first.

Backend: apply reviewed mission-1-commit-vocabulary-import.sql and mission-1-check-vocabulary-draft.sql in the same project. Both require active admin and invoker RLS. No table or bucket changes. Fast Upload's final commit passes create_only; legacy callers do not. No Supabase service key in Flutter.

Local verification: flutter pub get (regenerates lockfile and plugin registration), flutter analyze, flutter test test/vocabulary_import_test.dart test/vocabulary_fast_upload_test.dart, flutter run -d windows. Test invalid file, same term/different meaning, duplicate, filename conflict, failed network, changing theme during validation, successful publish and next, existing bulk import. Commit the resolved lockfile and generated platform files after successful dependency resolution. Do not merge until device verification.

## Adaptive audio input

Fast Upload on Windows/macOS/Linux accepts MP3, WAV, M4A, AAC, OGG, OPUS, FLAC, AMR and 3GP when a compatible FFmpeg installation is on PATH. MP3 remains unchanged; other formats are converted locally to 96 kbps mono MP3, 44.1 kHz, and preview uses the converted bytes. Original file is untouched. Input limit 50 MB for non-MP3, 10 MB for MP3; output limit 10 MB. Conversion times out after 60 seconds; invalid or unsupported recordings fail closed. No cloud conversion, new Dart package, schema, bucket, or public app changes. Mobile/web and existing batch-manifest importer remain MP3-only. Install FFmpeg once on Windows: `winget install --id Gyan.FFmpeg --exact`, completely restart VS Code/HQ, check `ffmpeg -version`. Run `flutter test --dart-define=KONTRIOS_FFMPEG_TEST=true test/vocabulary_fast_upload_test.dart` for real conversion smoke test.
